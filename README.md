# Sonsuz Çay Bekleme Simülasyonu

Bu repository, insanlık tarihinin en kritik sorununa çözüm üretir: Çay demlenirken beklemek.

## Neden Bu Proje?

Çay demlenirken geçen süre, evrenin en derin felsefi sorularını barındırır. Bu simülasyon, o süreyi sonsuz kılar ve size "bekliyorum" hissini en saf haliyle yaşatır.

**Uyarı:** Bu kod gerçekten çalışır. Sonsuza kadar bekler. Ctrl+C ile kurtulabilirsiniz. Belki.

## Kullanım

```bash
python cay_bekleyici.py
```

Sonra oturup izleyin. Veya git gidin, fark etmez. Kod bekler.

## Özellikler

- Sonsuz bekleme garantisi
- Dramatik mesajlar
- Gerçek zamanlı çay demlenme ilerlemesi (hayali)
- Felsefi derinlik (abartılı)
